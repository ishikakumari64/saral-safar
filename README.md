# Saral Safar — AI-Powered Bus Tracking & Passenger Counting

> **Smarter Bus Tracking. Real-Time Passenger Insights. Better Public Transportation.**

Saral Safar is a project focused on making public transportation smarter through computer vision and machine learning. It combines bus tracking with live passenger counting using a **YOLO-based object detection model** to provide better visibility into bus occupancy.

## Key Features

- **Bus Tracking:** Designed to support bus tracking and improve visibility into bus movement.
- **Live Passenger Counting:** Uses YOLO-based object detection to identify and count passengers from visual input.
- **Computer Vision:** Applies object detection techniques to analyze visual data.
- **Occupancy Insights:** Passenger counts can help understand bus occupancy and support more informed travel decisions.

## How It Works

1. **Visual Input:** The system receives visual data from the bus tracking setup.
2. **Object Detection:** The YOLO model processes the visual input to detect relevant objects.
3. **Passenger Counting:** Detected passengers are counted to estimate the number of people present.
4. **Tracking & Insights:** The project combines passenger-counting functionality with bus tracking to support smarter public transportation.

## Tech Stack

- **Machine Learning:** YOLO
- **Computer Vision:** Object Detection
- **Core Focus:** Passenger Detection, Counting & Bus Tracking

## Project Objective

The goal of Saral Safar is to explore how computer vision and machine learning can improve public transportation by combining bus tracking with passenger occupancy information.

## Potential Future Improvements

- Improve passenger detection in crowded environments.
- Integrate GPS-based bus location updates.
- Develop passenger occupancy dashboards.
- Evaluate detection accuracy under different lighting and camera conditions.
